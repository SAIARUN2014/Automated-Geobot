# Automated-Geobot
Environmental monitoring robot using Arduino UNO and ESP32-CAM.

## About the project 🌱🤖
Automated Geobot is an environmental monitoring robot designed to
move through an area and collect information about its
surroundings.

## Features

- 🌱 Soil moisture monitoring
- 🌡️ Temperature monitoring
- 💧 Humidity monitoring
- 🌫️ Dust monitoring
- 🌧️ Rain detection
- 📍 GPS location tracking
- 📷 Camera monitoring
- 📺 LCD information display
- 🛞 Motorized movement

## Hardware

- Arduino UNO
- ESP32-CAM
- Soil moisture sensor
- DHT11
- Dust sensor
- Rain sensor
- Motor driver
- BO motors
- LCD display
- GPS module
- Battery

## Project Status

🟡 Prototype completed — final body covering and documentation
in progress.

## Project Goal

The goal of Automate Geobot is to develop a mobile robot capable of
monitoring environmental conditions while moving through
an area.
