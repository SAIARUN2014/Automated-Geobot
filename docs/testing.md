# Automated Geobot testing

This document records the testing of the EcoBot's hardware and software.

## Sensor Testing

### Soil Moisture Sensor
- Purpose: Measures soil moisture.
- Test status: To be tested with the Arduino UNO.

### DHT11
- Purpose: Measures temperature and humidity.
- Test status: To be tested with the Arduino UNO.

### Rain Sensor
- Purpose: Detects rain or water.
- Test status: To be tested with the Arduino UNO.

### Dust Sensor
- Purpose: Detects dust/air-quality changes.
- Test status: To be tested with the Arduino UNO.

## Movement Testing

### L298N Motor Driver
- Purpose: Controls the BO motors.
- Test status: To be tested.

### BO Motors
- Purpose: Moves the EcoBot.
- Test status: To be tested.

## Camera Testing

### ESP32-CAM
- Purpose: Provides camera-based monitoring.
- Test status: To be tested.

## Display Testing

### 16×2 I²C LCD
- Purpose: Displays sensor and system information.
- Test status: To be tested.

## GPS Testing

### GPS Module
- Purpose: Provides location information.
- Test status: To be tested when the GPS module is available.

## Final Testing

After all individual components are tested, the complete Automated Geobot will be tested as one integrated system.
